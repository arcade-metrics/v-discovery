# 00 · Insumos: movido para `projeto/insumos.md`

Os insumos **IN-01 a IN-35**, extraídos das propostas do VUOO e do CIATec, valem para o produto inteiro e não só para a linguagem dos microjogos. Por isso o arquivo foi promovido para [`projeto/insumos.md`](../../projeto/insumos.md) em 29/10/2026, com os códigos congelados. Novos insumos entram lá, a partir de IN-36.

Todas as citações `[IN-nn]` neste estudo continuam válidas e apontam para aquele arquivo.
