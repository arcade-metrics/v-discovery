## O que o Core adota (proposta)

- `jurisdiction` = alfa-2 (`BR`) ou código de subdivisão (`BR-SP`); currículo estadual (C.CFW) leva a subdivisão.
- Nível abaixo de subdivisão (município, distrito escolar, *local authority*) entra como C.IDN com `scheme` do adaptador (`ibge-municipio`, `nces-lea`, `gss-la`) [I].
- Atenção: ISO usa **`GB`** para o Reino Unido; `UK` é reservado excepcionalmente e não é o código ISO [I: conferir].
