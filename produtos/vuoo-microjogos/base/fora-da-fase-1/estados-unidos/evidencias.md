## 2. Afirmações principais → fonte

|---|---|---|
| 1 | Ed-Fi DS v6.1.0 é a versão corrente; v5 e v6 são plenamente suportadas | E01, E10 |
| 2 | DS 6.0 trouxe mudanças incompatíveis: demografia e contato separados de StudentEducationOrganizationAssociation; identidades opcionais com múltiplos identificadores; novo modelo de avaliação; domínios Credential, Educator Preparation Program, Path, Performance Evaluation, Recruiting & Staffing | E02 |
| 3 | DS 6.1 acrescenta domínio Early Access para informação detalhada de IEP e eventos IDEA em nível de aluno | E02 |
| 4 | Identidade (chave natural) de StudentSchoolAssociation = Student + School + EntryDate; de StudentSectionAssociation e StaffSectionAssociation = pessoa + Section + BeginDate | E03 (`Enrollment.mmd`, `TeachingAndLearning-SectionsAndPrograms.mmd`) |
| 5 | Section = SectionIdentifier + CourseOffering; CourseOffering = LocalCourseCode + School + Session; Course = CourseCode + EducationOrganization; Session = School + SchoolYear + SessionName | E03 |
| 6 | Grade = StudentSectionAssociation + GradingPeriod + GradeType | E03 (`StudentAcademicRecord-ReportCard.mmd`) |
| 7 | School, LEA, SEA, ESC, PostSecondaryInstitution, CommunityOrganization, OrganizationDepartment e EducationOrganizationNetwork são "IsA" EducationOrganization | E03 (`EducationOrganization.mmd`) |
| 8 | Person no Ed-Fi tem identidade PersonId + SourceSystem e é referência opcional de Student/Staff | E03 |
| 9 | O UDM deixa "Person" fora como entidade unificada porque papéis de aluno e professor são distintos | E05 |
| 10 | Descritores: "Only descriptor values in the 'ed-fi.org' namespace are part of the standard"; valores do namespace `uri://ed-fi.org` não devem ser editados; desde DS 4.0 há descriptor mappings | E01, E04 |
| 11 | Parent foi renomeado Contact no DS 5.0 (StudentParentAssociation → StudentContactAssociation) | E08 |
| 12 | OneRoster 1.2: User tem `roles` (cada Role no contexto de uma Org, com roleType primary/secondary, begin/end); "A user must have at least one role and each role is assigned in the context of a single org" | E11 §3.3, §4 |
| 13 | OneRoster 1.2: course = programa de estudo atribuído a uma org; class = atividade de ensino de um course | E11 |
| 14 | Enumerações OneRoster 1.2 (valores) e regra `ext:` para extensões de vocabulário | E11 §6.3, §8.1 |
| 15 | Edu-API v1.0 é Final; foco em ensino superior; Affiliation (pessoa↔organização) e Enrollment (pessoa↔oferta); Collection→Course→Component; escopos `core.readonly` e `core.readonly.privacy` | E13 |
| 16 | CEDS: arquivo de elementos na versão 14.0.0.0; licença Apache-2.0; release anual | E17 |
| 17 | CCSS: identificadores em notação de pontos, URI e GUID; XML segue esquema CEDS | E19 |
| 18 | CCSS adotado por 41 estados, DC, 4 territórios e DoDEA | E20 |
| 19 | NGSS: códigos de PE (ex.: 2-PS1-2) = série/banda + disciplina/ideia central + ordem; foundation boxes SEP/DCI/CCC; conexões com CCSS | E25 |
