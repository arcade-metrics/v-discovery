## 1. Inglaterra: code sets do CBDS (May 2026) [S-UK-02]

### CS096 Pupil SEN Provision
| Código | Descrição |
|---|---|
| N | No Special Educational Need |
| E | Education, Health and Care Plan |
| K | SEN Support |
| S* | Statement (só histórico no CTF) |
| A* | School Action or Early Years Action (só histórico) |
| P* | School Action Plus or Early Years Action Plus (só histórico) |

### CS071 Pupil SEN Type (Census "primary/secondary need")
| Código | Descrição |
|---|---|
| SPLD | Specific Learning Difficulty |
| MLD | Moderate Learning Difficulty |
| SLD | Severe Learning Difficulty |
| PMLD | Profound & Multiple Learning Difficulty |
| SEMH | Social, Emotional and Mental Health |
| SLCN | Speech, Language and Communication Needs |

| VI | Vision Impairment |

CS077 (Special School Type, tipo de necessidade para o qual a escola é aprovada): mesmos códigos, sem DS e NSA.

### CS110 SEN setting (quando não há URN/UKPRN)
OLA (arranjo da LA, s.61 CFA 2014); EHE (educação domiciliar eletiva); EYP (provedor EY sem URN); OPA (arranjo dos pais, s.42(5)); OTH; NEET (16–25); NIEC (fora de educação, aviso de cessação emitido); NIEO (fora de educação, outro).

### CS007 Pupil Enrolment Status
| Código | Descrição |
|---|---|
| C | Current (single registration at this school) |
| M | Current Main (dual registration) |
| S | Current Subsidiary (dual registration) |
| F | FE College |
| O | Other Provider |
| G | Guest (não registrado, frequenta algumas aulas; só no MIS, não no censo) |
| P | Previous |

### CS086 NC Year Group
E1, E2 (early years), N1, N2 (nursery), R (Reception), 1–14, M (turma multisseriada, só em Class Year Group), X (currículo nacional não seguido, só escolas especiais).

### CS037 Class Key Stage
F (Foundation: nursery ou reception), 1, 2, 3, M (misto).

### CS036 Class Type
N (Nursery class), O (Not a nursery class).

### CS012 Contact Relationship
CAR Carer; CHM Childminder; DOC Doctor; FAM Other family member; FOF/FOM Foster Father/Mother; HTC Head Teacher; OTH Other Contact; PAF Father; PAM Mother; REL Other Relative; RLG Religious/Spiritual Contact; STF/STM Step Father/Mother; SWR Social Worker; TCH Teacher.

### CS066 Attendance codes (por sessão, desde 2024/25)
`/` presente manhã; `\` presente tarde; L atrasado antes do fechamento; U após fechamento; B, K, P, V, W atividade educacional aprovada (outra, outro local, esporte, visita, estágio); D outra escola onde é registrado; C, C1, C2, J1, M, R, S, T, X ausência com permissão (circunstância excepcional, apresentação regulada, horário reduzido, entrevista, consulta médica, observância religiosa, estudo para exame, criança móvel, fora da idade compulsória); E excluído sem provisão; G férias sem permissão; I doença; N não estabelecido; O outras circunstâncias; Q falta de transporte da LA; Y1–Y7 impossibilidade (transporte, emergência, instalações, escola fechada, detenção, saúde pública, outra); Z e # não vão ao censo. H e J usados até 31/7/2024.

## 2. Inglaterra: SEND Code of Practice [S-UK-11]

| Termo | Significado |
|---|---|
| SEN Support | apoio da escola sem EHC plan (código K) |
| EHC plan | plano estatutário de educação, saúde e assistência social, 0–25, mantido pela LA (código E); seções A–K |
| EHC needs assessment | avaliação que pode levar ao plano |
| Graduated approach | ciclo assess, plan, do, review |
| Broad areas of need | communication and interaction; cognition and learning; social, emotional and mental health; sensory and/or physical needs |
| SENCO | coordenador de SEN da escola |
| Resourced provision / SEN unit | provisão especializada designada pela LA dentro de escola regular |
